# המפה באתר שלך

אפשר לשים את אפליקציית הרשת של MapAround בכל דף אינטרנט, כמפה בלבד: המסלול של טיול בפוסט בבלוג,
נקודת מפגש בדף של מועדון, האזור של טיול. זו אותה מפה כמו באפליקציה, עם שכבות המפה ותצוגת התלת־ממד,
ואין מה להתקין או להירשם. המבקרים מזיזים ומגדילים אותה, ו**פתיחה ב־MapAround** (הכפתור העליון)
פותח אותה באפליקציית הרשת המלאה, שבה אפשר לשמור את המסלול או לתכנן מסלול משלהם.

## הקוד

שמים את זה במקום שבו המפה צריכה להיות, עם המקום הרצוי בכתובת:

```html
<iframe src="https://maparound.app/app/?embed#map=13/31.47/35.38"
        title="מפה" width="100%" height="450" style="border:0" loading="lazy"></iframe>
```

`?embed` הוא מה שהופך אותה למפה בלבד. `#map=13/31.47/35.38` הוא המקום שבו היא נפתחת: זום, קו
רוחב, קו אורך, כמו ב־openstreetmap.org (הכתובת של אפליקציית הרשת עצמה מראה אותו כשמזיזים את המפה,
כך שאפשר להעתיק אותו משם).

## מסלול

**מתוך MapAround.** ב**ספרייה** פותחים את התפריט ⋮ של מסלול ובוחרים **הטמעה באתר**. הקוד מועתק:
מדביקים אותו בדף. הקו עצמו נמצא בכתובת שבקוד, כמו בקישור ששותף, כך ששום דבר לא מועלה לשום מקום.
מסלולים ארוכים מצטמצמים ל־500 נקודות בלי לאבד את הצורה, והגבהים נשמרים. המפה מתאימה את עצמה
למסלול, ובראשה השם, האורך והטיפוס שלו.

**קובץ GPX באתר.** שמים את הכתובת שלו אחרי `gpx=`:

```html
<iframe src="https://maparound.app/app/?embed&gpx=https://example.org/hikes/wadi-qelt.gpx"
        title="ואדי קלט" width="100%" height="450" style="border:0" loading="lazy"></iframe>
```

הדפדפן של המבקר הוא שקורא את הקובץ, ולכן האתר שבו הוא נמצא צריך לאפשר לאתרים אחרים לקרוא אותו
(CORS, הכותרת `Access-Control-Allow-Origin`). GitHub Pages והקבצים הגולמיים של GitHub
(raw.githubusercontent.com) מאפשרים; הרבה אתרים לא, ואז המפה אומרת שלא הצליחה להשיג את הקובץ. המסלול
מקבל את השם שבתוך הקובץ, ואם אין, את שם הקובץ; נקודות הציון שבו מופיעות כמקומות על המפה. אם בכתובת
הקובץ יש `?` או `&` משלה, צריך לקודד אותה קודם (`encodeURIComponent` ב־JavaScript).

## נקודה

הסיכה של openstreetmap.org, `mlat=` ו־`mlon=`:

```html
<iframe src="https://maparound.app/app/?embed&mlat=31.4655&mlon=35.3870#map=15/31.4655/35.3870"
        title="נקודת המפגש" width="100%" height="450" style="border:0" loading="lazy"></iframe>
```

## כל מה שאפשר לשים בכתובת

| בכתובת | מה זה עושה |
|---|---|
| `embed` | המפה בלבד. בלי זה הדף הוא אפליקציית הרשת כולה. |
| `#map=zoom/lat/lon` | המקום שבו המפה נפתחת. עם מסלול, המפה מתאימה את עצמה למסלול במקום זה. |
| `mlat=…&mlon=…` | סיכה. |
| `#track=…&n=…` | מסלול, כמו ש**הטמעה באתר** יוצרת אותו. |
| `gpx=<כתובת>` | קובץ GPX מאתר שמאפשר את זה. |
| `layer=<מפה>` | המפה שמוצגת: `osmfr` (OpenStreetMap, ברירת המחדל), המפות הווקטוריות `ofm_liberty` ו־`ofm_positron` (של OpenFreeMap, באפור בהיר), `opentopomap`, `cyclosm`, `hot`, `esri_topo`, `esri_street`, `esri_imagery` (לוויין), `osmde`, ולארץ שלהן `swisstopo`, `basemap_at`, `kartverket`, `ign_plan`, `ign_ortho`, `usgs_topo`. |
| `trails=0` | בלי שבילי ההליכה המסומנים שמצוירים מעל המפה (waymarkedtrails.org). |
| `lang=he` או `lang=en` | השפה של הכפתורים; אחרת השפה של הדפדפן של המבקר. |
| `data=maps` | תצוגת הנתונים על המפות של MapAround: כל אזור צבוע לפי מצב המפה שלו (נבנתה בבנייה החודשית האחרונה, ישנה יותר, אין), כמו ב[דף התמיכה]({{ '/he/support' | relative_url }}). |

אפשר לשים את האפשרויות אחרי `?` או אחרי `#`, מחוברות ב־`&`, למשל
`…/app/?embed&layer=opentopomap&trails=0#map=13/31.47/35.38`. המבקרים עדיין יכולים לבחור מפה אחרת
ב**שכבות מפה**; הבחירה נשמרת עד שעוזבים את הדף. **פתיחה ב־MapAround** שומרת את התצוגה, הסיכה,
המסלול ותצוגת הנתונים, אבל לא את `layer`, `trails` ו־`lang`: האפליקציה המלאה נפתחת עם ההגדרות של המבקר עצמו.

## מה הדפדפן של המבקר עושה

המפה המוטמעת לא קוראת ולא שומרת שום דבר של המבקר: לא את ההגדרות, המסלולים או המקומות שלו
ב־MapAround, גם אם הוא משתמש באפליקציית הרשת באותו דפדפן, והיא לא מבקשת את המיקום שלו. הדפדפן מוריד
את האפליקציה מ־GitHub (כמה מגה־בייט בפעם הראשונה, ואחר כך מהמטמון שלו), את האריחים של המפה מהשרתים
שלה, ואת קובץ ה־GPX מהאתר שלו. מסלול שנמצא בכתובת אחרי `#` לא נשלח לשום שרת.

## כדאי לדעת

- **תנאי השימוש של שרתי המפות.** המפות מגיעות מהשרתים שלהן (OpenStreetMap צרפת, OpenTopoMap, Esri,
  סוכנויות המיפוי הלאומיות…), שחינמיים לשימוש קל. אתר עמוס כדאי שיבדוק את התנאים שלהם.
- **צריך להשאיר את הקרדיטים גלויים**: מקורות המפה כתובים בתחתית שלה, והרישיונות של המפות מבקשים
  את זה. לא לחתוך את המסגרת.
- **בטלפון** המפה מקבלת את הנגיעות שבתוכה, כך שהדף נגלל רק מחוץ לה. מפה נמוכה מהמסך (450 הפיקסלים
  שבקוד, או פחות) משאירה לזה מקום.
- **מסגרת עם `sandbox`** צריכה לפחות `allow-scripts allow-same-origin allow-popups`, האחרון בשביל
  **פתיחה ב־MapAround**. בלי `sandbox` לא צריך כלום.
- הדפדפן צריך להיות עדכני מספיק לאפליקציית הרשת: Chrome, Edge, Firefox או Safari מ־2024 ואילך. בדפדפן
  ישן יותר מופיעה במסגרת הודעה במקום המפה.
